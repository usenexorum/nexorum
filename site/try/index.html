What am I seeing?

A coding agent with a long-term memory, and the background pass (a dream) that keeps that memory accurate.

Chat. You talk to the agent. It starts every session with a small context digest and can call remember, recall and read_document. Open a tool call to see exactly what it returned.

Transcripts and notes. An ended session becomes a transcript, with secrets redacted first. Notes are short memories the agent saved itself. Either can be wrong or stale.

Dream. One analyzer per input checks it against the wiki and writes what is true; then one organizer merges duplicates, dates changes and keeps the index current. Watch them walk to the shelves they read and write.

Review. The result is a proposal: line diffs of every page. Approve updates the wiki and the digest; Reject changes nothing.

Recorded or Live. Recorded replays a scripted example: no model runs, but the search, the scrubber, the diffs and the memory come from Nexorum's own engine, running in your browser. Live runs the same engine with a real model through this site's capped proxy. Nothing is saved on your machine.
