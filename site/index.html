Pricing

Free, and your data stays yours.

Nexorum is open source software that runs on your machine. There is nothing to sign up for. Notes, transcripts, the wiki and its history are files under ~/.nexorum; delete the folder and the memory is gone.

The only thing that costs money is the model you choose to dream with, and you pay that provider directly. A dream sends transcripts, notes and wiki pages to the LLM you configure, and nowhere else.

Workflow

How it works

Your agent writes notes and its sessions are saved as transcripts. A dream looks back over them with hindsight and proposes updates to a small wiki. The next session starts from the approved version.

01

Your agent works

Claude Code hooks or the MCP server save short notes and session transcripts to ~/.nexorum. Known secret patterns are redacted before anything is written.

02

Memory is searchable

Notes and wiki pages are ranked with BM25 keyword search, and the agent can follow links between pages from the index. No embeddings, no vector database.

03

A dream corrects it

nexorum dream checks the wiki against your transcripts, fixes stale or wrong facts, merges duplicates and links pages. It writes a proposal; nothing changes until you apply it.

04

The next session knows

A short index of the wiki is loaded at session start, so your agent does not have to rediscover what earlier sessions already learned.

Safety

Memory that gets reviewed, not just stored

Notes are searchable right away. Dreams turn notes and transcripts into a small wiki and propose fixes. You decide what is applied, and everything stays in files you own.

A wiki your agent can navigate

Plain markdown files in ~/.nexorum, linked to each other, with an _index.md that lists them. Open them in any editor, or let the agent follow the links.

Every change is a version

Each write to the live wiki, from a dream you applied or from you, is recorded. See the history of a page and restore an earlier version.

0 changes without you

A dream only writes a proposal. Nothing reaches the live wiki until you run nexorum apply, and a page changed since the dream started is skipped.

Dream with a key, or without one

Use your own key (Anthropic by default, or any OpenAI-compatible endpoint), or let the agent you already run dream through two MCP tools. Key runs are estimated first and stop at your budget.

Secrets are scrubbed

API keys, tokens and private keys are replaced with [REDACTED] markers in transcripts, notes and anything a dream writes, before they reach disk.

Review, diff, apply or reject

Read the line diff against your live wiki, then apply or reject it. The agent can read proposals but never apply them.

FAQ

Questions, answered

More in the docs, or ask us on X.

What does a dream change?
Nothing, until you apply it. A dream writes a proposal: line diffs of every page it wants to add, change or delete. A page that changed since the dream started is skipped, not overwritten.
Do I need an API key?
No. Use your own key (Anthropic by default, or any OpenAI-compatible endpoint, including a local router), or let the agent you already run do it through two MCP tools. Key runs are estimated first and stop at the token budget you set.
Where is my memory kept?
In ~/.nexorum, one space per project, as plain files. Open them in any editor, commit them to git, or delete the folder.
Are secrets safe?
Known patterns such as API keys and tokens are replaced with [REDACTED] markers in transcripts, notes and anything a dream writes, before they reach disk. This catches known patterns, not everything.
What is $NEXR?
The community token for Nexorum. You never need it to use the software.
